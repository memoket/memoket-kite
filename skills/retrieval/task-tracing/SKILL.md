---
name: task-tracing
description: Trace a task and its latest state reported in conversation.
---

Anchor the query with a task topic, entity, literal text or stable `state_key`.
Set `follow_states: true` when a person or phrase is a clue to the task.
Follow the state history within the requested topics, sources, projects and dates.
Check `unresolved_entities` before drawing conclusions about the named people.
Use dated, explicitly reported assignments, blockers and updates. Preserve ambiguous or missing states.
Describe the current result as reported in conversation unless a separate task system verifies it.
